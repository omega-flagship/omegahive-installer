The installer enables proposal tests for its disposable `small-app` repository on macOS. The project check requires nonempty HTML, CSS and JavaScript files, then checks `app.js` as a JavaScript module with the installed Node. It checks syntax and required files; it does not establish that an app meets the person's request.

The source adapters are applied to the published `omegacode-309df.tgz` after checking its digest. The resulting Python modules must match `PORTABLE_SERVICE_RELEASE` in `hive/core/code.py`. Ordinary API handlers are unchanged. Purpose routes accept the hive's Python command and return its authenticated sandbox receipt. The proposal-test envelope keeps `max_runtime_seconds` at 600, as required by `hive/API.md` and `modules/code/src/code_proposal.py`. Live launch admission still checks the shorter lease and remaining budgets.

The Code config pins the installed Python, Node and sandbox-exec executables by SHA-256. Code sends an authenticated snapshot of its retained candidate to the hive's existing `code-project-test` program. The installer pins that program and configures its Python runtime. The hive owns admission, once-only dispatch, cleanup observation and settlement. Its strict Mac sandbox denies network access and fork. The checker replaces itself with Node to check syntax, preserving that process boundary. `HIVE_PROPOSAL_TEST_ARGV_PREFIXES` permits only the pinned Python running `check_app.py`. The repository's `proposal-only` policy refuses ordinary native execution. A person can inspect the generated config in the hive's `code/config.json`.

First startup leaves the purpose listener off until ordinary service enrolment completes. `omegahive.sh create` then enables it and restarts Code. Subsequent setup preserves enrolment, the operator token and existing app files. Upgrades add or migrate the installer checker in its own commit while preserving unrelated staged changes. An unknown personal checker is refused rather than overwritten.

The installer also selects `disposable-app-files-v1` for `small-app`. Automatic copying may write only `index.html`, `app.js`, `style.css` and `README.md`. It refuses file deletions, empty files, truncation, stale source and other paths. It classifies file effects; it does not claim to preserve program semantics. Code still checks the original person's scope, proposal provenance, live authority and exact generation before mutation. The separate person-driven Code drawer Accept path is unchanged.

To disable candidate tests, stop the hive, set `HIVE_PROPOSAL_TEST_CLAIMS=off` in `hive.env` and `proposal_tests_enabled` to false in `code/config.json`, then restart. Remove `copy_effect_policy` from that config to disable controller copy application as well. To roll back a release, reinstall the prior complete installer release so its service digest, source adapters and hive guard agree; do not change the digest alone.
